# 车型知识库检索精度与覆盖度治理(rag-precision)

## Goal

修复「海狮08 文章价格/续航错误、EV/DM-i 混淆」暴露的 RAG 三层缺陷,使文章生成的数值性表述有据可查、版本不混淆、缺失可感知。

## 诊断结论(2026-09-03 日志取证,证据已核实)

现象:项目15「海狮08与大唐EV怎么选?」生成的文章价格错误(如 20.99/21.98/26.64 万不在任何官方区间)、续航错误、未区分海狮08 EV 与 DM-i。

取证事实链:

1. **数据完整**:比亚迪同步已采集海狮08EV(model 55)与海狮08DM-i(model 56)两车型;清洗参数 3197 行;DM-i 动力块含 1.5T 发动机/115kW 等数值;EV 尺寸块含 5115×1999×1800 等。**数据不是缺失的**。
2. **检索只打了单车型**:两次 `searchTopK` 均 `WHERE model_id=55`(EV),大唐EV(39)/DM-i(56)从未被查询——项目仅关联了海狮08EV 一个车型。
3. **top8 配额被劣质块挤占**:命中 8 块 = 车型概述×1 + 「海狮08EV参数表及配置表」表头块(仅 2 行:分组名+车型名,零参数值)+ 购车权益×6。尺寸/动力/新能源配置等**含数值的核心参数块全部没进 top8**(它们存在且带数值,如动力块「前电机最大功率(kW):200」)。
4. **表头块噪音**:`sparkora_car_param_group` 存在 sort=0 的「XX参数表及配置表」纯表头分组,其下仅「车型」一行,切块后成为零信息块,且因与主题名相似得分最高(0.6995),排第 2。
5. **单查询检索**:`query = project.topic` 整句(「海狮08与大唐EV怎么选?」),与「续航」「电池」「价格」等参数级子问题语义不对齐,权益块因措辞相似反而高分。
6. **运行版本**:生成时后端为 S6 旧链路(17:18 启动,S6.1 未部署);但分数 0.63~0.71 远超 0.5 门槛,S6.1 判 OK——**S6.1 不拦截本类错误**(其定位是检索失败/整体不相关,非内容缺口)。

## 根因分层

| 层 | 缺陷 | 后果 |
|---|---|---|
| 数据层 | 表头组「参数表及配置表」产零信息块;参数按分组块切,数值散在 15+ 块里 | 噪声块高分挤占配额;单个块信息密度低 |
| 检索层 | ① 项目只关联 1 个车型(用户未选 DM-i);② topK=8 单查询;③ 权益块与主题措辞相似抢分 | 关键参数块不出现在上下文 |
| 生成层 | prompt 未告知「哪些参数知识库未覆盖」 | AI 在数值缺口处编造,用户无法感知 |

## 方案(P0 → P2)

### P0 检索层修复(本任务实施,收益最大)

1. **多动力版本关联**:项目编辑页车型选择支持同车系多版本;或检索时对「海狮08」自动展开同系车型(名称前缀匹配,如 EV/DM-i 互为变体)——取两者并集检索。
2. **块类型配额检索**:`buildContextForModels` 改为按 `chunk_type` 分层配额(如 MODEL_INFO ≤2、PARAM_GROUP ≥5、权益类 ≤1),避免单一类型挤占 topK;表头块(参数行 <2)在切块时直接跳过。
3. **参数级子查询**:从 brief 大纲/关键词派生子查询(「海狮08EV 价格」「海狮08EV CLTC 续航」「海狮08DM-i 油耗」…)逐项检索合并,替代单次整句 topic。
4. **prompt 覆盖度声明**:注入知识块时生成「已覆盖参数清单」;对大纲提到但未命中的参数,显式告知 AI「知识库未覆盖,禁止给出具体数值,用定性表述+factRisks 标注」。

### P1 数据层增强(拆后续任务)

- 参数表分组块改为「参数名:值」逐项入向量(粒度细但块多);或按「车型+分组+关键数值摘要」合成高密度块。
- chunk_text 首行加车型全名(EV/DM-i 显式区分),消除跨版本混淆。

### P2 生成侧防线(S6.1 延伸)

- 生成后校验:正文中出现的价格/续航数值若不在命中块内,标记 factRisks(可先 warn 日志观察)。

## Acceptance Criteria(本任务,只做 P0)

- [ ] AC1 同主题下 EV+DM-i 数据均能进入上下文(或明确告知用户需关联 DM-i 并在前端可见)。
- [ ] 表头零信息块不再产生/不再被检索。
- [ ] top8 中核心参数块(尺寸/动力/新能源)至少占 5 席(用真实项目15 query 验证命中构成)。
- [ ] 文章中「海狮08」价格/续航数值与知识库一致,或该处明确「未覆盖」不写具体数。
- [ ] 现有 `CarRagServiceTest` 全绿 + 新增子查询/配额单测。

## Constraints
