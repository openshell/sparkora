# 知识中心车型 Tab 同步与交互整改

## Goal

修复车型缩略图误用官网详情图的问题，并系统整改知识中心「车型」Tab 的同步闭环、状态可信度、信息展示与交互体验，使该 Tab 达到与「知识库」「信源」Tab 一致的产品完整度。

本次范围：**P0 + P1 完整整改**（用户 2026-10-21 确认）。P2 向量重建异步化、服务端分页另开任务。

## Background（已确认事实，含代码锚点）

- 知识中心入口 `frontend/src/views/KnowledgeCenter.vue`；车型 Tab `frontend/src/views/knowledge/CarKnowledgePanel.vue`（300 行）。
- 缩略图取 `introImageUrls[0]`（`CarKnowledgePanel.vue:157-160`），`intro_images` 来自官网 `goodsInfo.introduce`（详情图），故卡片全是详情图。
- 官网 `goodsListForSearch` / `getGoodsInfoById` 均返回 `img`（车辆主体图，透明 PNG，实测绝对 URL）；`CarSync.vue` 目录卡片已用 `c.img`，但 `GoodsInfoDto.Item` 未接收 `img`（`GoodsInfoDto.java:25-35`），`car_model` 无封面字段。
- 同步失败只写任务 `failed_items`，未回写车型 `sync_status`/`last_sync_error`（`CarSyncJobService.java:167-178`）；开始时已置 `SYNCING`（`:252-258`）→ 失败车型永久停在「同步中」。
- `lastSyncError` 字段存在但从未写入，前端不展示。
- 知识中心与 `/car/sync` 能力重复：前者仅单车型建任务 + 跳转；后者有目录全选、批量同步、图片补入库、明细与重试。
- 车型 Tab 的进度只在当前页面发起任务时显示，刷新/切 Tab 即丢；后端已有 `GET /api/car/sync/jobs` 未使用。
- 统计「车型图已入库」取全库 `source=byd` 图片总数（`:187-190`），非车型覆盖率，语义误导。
- 「重建全部向量」为同步阻塞接口（`POST /api/car/models/rebuild-all`，前端 300s 超时，`api/index.js:122`）。
- 无排序、分页、刷新、批量选择、失败原因/重试、图集、封面选择。
- 卡片缩略图 `4/3 + fit="cover"`（`:273-274`）；主体图为透明 PNG，cover 会裁切且底色不一致。
- `CarDetail.vue` 只展示价格、版本与参数表，不展示图片与卖点。
- 删除确认未说明「不删共享图库资产」（`:232`）。
- 列表按 id 倒序（`CarModelService.java:109`）。

## Requirements

### R1 车型封面（主体图）— P0

- 全量同步、轻回填、增量三条链路采集官网 `img` 并入库为车型封面；封面与详情图集分离，互不覆盖。
- 封面缺失时前端回退详情图首图；均无图展示统一占位。
- 详情页展示封面与详情图集。
- 存量车型通过一次「图片补入库」回填封面，不要求逐台手动同步；回填幂等。

### R2 同步状态可信 — P0

- 单车型同步失败必须落为「失败」并记录失败原因与时间，不得停留「同步中」。
- 任务终态与车型终态口径一致；「同步中」只用于确实执行的车型。
- 成功同步清除历史失败原因。

### R3 失败可见与可处置 — P0

- 卡片可查看最近失败原因（截断 + tooltip），详情页完整展示。
- 失败车型可一键重试，无需跳转同步页。
- 任务明细区分失败与跳过/备注；失败项可重试。

### R4 同步闭环内聚 — P1

- 车型 Tab 内直接打开官网目录抽屉完成选择与同步，不再强制跳转 `/car/sync`。
- 进入 Tab 可看到最近任务状态与进度；刷新/切 Tab 返回可恢复。
- 任务运行中阻止创建冲突任务并提示。
- `/car/sync` 保留，与知识中心复用同一套组件与轮询逻辑。

### R5 浏览效率 — P1

- 关键词/网络/状态筛选，显示结果数，支持一键清除。
- 排序：最近同步（默认）、名称、价格。
- 手动刷新入口。
- 统计条：全部、已同步、失败、同步中、封面覆盖（非全库图片总数）。
- 批量选择、批量同步、批量删除（二次确认 + 结果汇总）。
- 当前数据量（47 台）前端排序/筛选；服务端分页列入 P2。

### R6 图片体验 — P1

- 主体图缩略图 `fit="contain"` + 纸色底，避免透明 PNG 裁切。
- 详情页支持看大图与图集（原图 URL）。
- 详情页补齐封面、卖点、价格与图集。

### R7 运维动作安全与可理解 — P1

- 「重建全部向量」移入「运维」下拉，保留二次确认并说明耗时/影响。
- 删除确认明确「删除车型及参数/向量，不删除共享图库资产」。
- 长耗时动作有量级提示与防重复触发。

### R8 视觉与交互一致性 — P1

- 三态齐全（卡片骨架、错误 + 重试、空态引导）。
- 控件密度与知识库/信源 Tab 一致；图标显式引入；交互元素有 `:focus-visible`。
- 批量选择 checkbox 恒定可见，不依赖 hover。

## Technical Notes

- 封面独立字段 `cover_image_id`（图库 asset id），派生 `coverImageUrl`；`intro_images` 语义不变。
- `img` 不加入同步指纹，避免存量指纹全部失效触发全量重清洗/重嵌入；封面更新随全量同步或「图片补入库」发生（已知限制，写入规格文档）。
- 迁移版本用 `V26`：main 当前最新 V23，未合并的 BYD 分支占用 V24/V25；合并顺序风险见设计文档。
