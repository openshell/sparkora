# 图库图片标签功能与交互优化

## Goal

图库新增「图片标签」能力：独立标签表存储，上传/AI 生图时通过全局预选标签随图入库；卡片与批量管理支持补打/移除标签；图库页支持按标签筛选。比亚迪来源图片全面纳入图库管理并自动分类（车型介绍图、新闻封面图）。同步审查图库页样式与交互并做优化。

## Background

- 图库现状（S10 重构后）：`sparkora_image_asset` 四来源统一入库（upload / ai-text2img / ai-img2img / byd），内容哈希去重，服务端分页 + keyword/source/projectId 筛选；前端 `ImageLibrary.vue` 有上传、AI 生图抽屉、批量管理、密度切换、连续预览。
- 痛点：入库后无组织维度（只有来源/项目），找图靠文件名/提示词搜索；无标签体系。
- BYD 图片现状（09-13 勘察）：
  - 车型介绍图：已入库（`source=byd`，`CarModelService.persistIntroImages`，CarModelService.java:339），但无分类——不知道属于哪个车型；
  - 新闻封面图：仅存 URL 字符串（`sparkora_news.image_url`，NewsService.java:190 不下载），未进图库；
  - 新闻正文内嵌图：解析时只记 `[图片] <src>` 标记行，未下载不入库。

## Requirements

### R1 标签数据模型（独立标签表）

- 新建 `sparkora_image_tag`：标签与图片的关联记录（tag_name + image_id），支持多图多标签。
- 标签按名称使用（不先建独立标签字典表）；同一图片同一标签不重复。
- 索引：image_id、tag_name 各一个，支持按图查标签与按标签查图。
- schema.sql 幂等建表；entity/mapper 同步新增。

### R2 打标入口

- **上传/AI 生图时全局预选**：图库页工具条提供「上传标签」预选控件（多选/可新建），上传与 AI 生图（文生图/图生图/重生成除外）时把预选标签随图写入。
  - 重生成（regenerate）沿用源图标签（新图继承，保证同主题成组）。
  - **去重命中（dedupeHit）时合并补上**：复用已有图的同时，把本次预选但已有图缺失的标签补写到已有图上（用户明确选了标签，不生效反而突兀）。
- **卡片编辑**：图片卡片上提供「编辑标签」入口，单图增删标签。
- **批量管理**：批量选择态下支持「补打标签」与「移除标签」两种批量操作。

### R2b BYD 图片分类入库（09-13 新增范围）

- **车型介绍图自动分类**：`persistIntroImages` 入库时自动打标签 `车型-<车型名>`（如 `车型-海豹`），今后同步持续生效；存量已入库的 byd 图启动时一次性追溯补打（按 `car_model.intro_images` 的 asset id 列表逐车型补标，幂等可重跑）。
- **新闻封面图纳入图库**：新闻同步 `upsertOne` 时下载封面图走统一入库管线，`source=byd-news`，自动打「新闻」标签（可选 `新闻-<tagNames>` 细分标签不做，MVP 只打「新闻」）；`sparkora_news.image_url` 保留原语义（原始 URL 留痕，不破坏现有新闻页展示）。单图下载失败仅告警不阻断新闻入库（同车型图容错先例）。
- **来源白名单扩展**：`SOURCES` 加 `byd-news`；图库前端 `SOURCE_LABELS` 加「比亚迪新闻」。
- 新闻正文内嵌图**不入库**（图片型新闻多为装饰长图，量大噪音高——范围外）。

### R3 标签筛选

- 图库列表接口 `GET /api/images` 支持 `tag` 参数：命中任一标签即返回（该图全部记录照常返回）。
- 前端工具条增加标签筛选控件（输入联想已有标签），chip 条展示。
- 新增 `GET /api/images/tags` 返回全库标签列表（名称 + 引用数量），供筛选联想与预选控件复用。

### R4 展示

- 图片卡片展示该图标签（hover 层元数据区/移动端常显区），点击卡片标签可触发筛选。
- 列表接口返回每张图的标签集合（entity 非持久化字段 `tags`）。

### R5 样式与交互审查优化

- 由实现侧顺带审查 `ImageLibrary.vue` 与相关交互，输出并落实低风险优化项（布局/触控目标/空态/加载态/可访问性等），大改动项列清单留待后续任务。
- 已知具体问题（审查中确认，随标签功能一并修）：
  - AI 生图抽屉文生图/图生图两个 tab 共用同一个 `aiPrompt`，切换 tab 内容互相污染；
  - 参考图选择弹窗只展示当前筛选下的第一页图片，无法翻页/搜索。

## Non-goals

- 不做标签管理页（改名/合并/删除全局标签），标签随关联记录自然增减。
- 不做图片描述/EXIF 等其他元数据。
- 不做跨工作区标签。
- 新闻正文内嵌图不入库（装饰长图噪音大，量级风险）。
- BYD 图不做人工二次审核流程（自动打标后可人工改）。

## Acceptance Criteria

- [ ] 上传图片时可预选标签，入库后该图携带所预选标签；不选则无标签。
- [ ] AI 文生图/图生图候选图携带预选标签；重生成图继承源图标签。
- [ ] 图片卡片可编辑单图标签（增/删），改动即时生效并反映在筛选列表。
- [ ] 批量管理可对选中图补打/移除标签。
- [ ] 图库页可按标签筛选，列表接口 tag 参数生效；标签筛选与其他筛选（来源/项目/关键字）可组合。
- [ ] `GET /api/images/tags` 返回标签 + 引用数量；预选与筛选控件数据同源。
- [ ] 卡片展示标签，点标签可触发筛选。
- [ ] 车型同步入库的介绍图自动携带 `车型-<车型名>` 标签；存量 byd 图启动追溯补打完成（重跑幂等）。
- [ ] 新闻同步入库的封面图进图库（source=byd-news）并携带「新闻」标签；下载失败不阻断新闻入库。
- [ ] 图库来源筛选含「比亚迪新闻」且可筛出 byd-news 图。
- [ ] AI 抽屉双 tab prompt 独立;参考图弹窗支持搜索/翻页（或等价可用方案）。
- [ ] VIEWER 可读标签/筛选;打标/改标仅 ADMIN/EDITOR。
- [ ] `mvn -q -DskipTests compile` 通过;`npm run build` 通过。
- [ ] spec（docs/s0-spec.md §10 图库接口契约）同步更新标签相关字段与接口。
