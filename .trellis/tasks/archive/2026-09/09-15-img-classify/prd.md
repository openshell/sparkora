# 图片主题分类与来源追溯地基（子A）

## Goal

让比亚迪新闻图片可被「按主题 + 按时间」精确找到，并能追溯回来源新闻。这是父任务 `09-15-image-smart-app` 的地基，子B（语义检索）依赖本任务产出的标签与 `source_ref`。

## Dependencies

- **前置**：无（本任务是最上游地基）。
- **被依赖**：子B（图片语义向量检索）用本任务的标签 + 来源文本做嵌入；子D 便宜路径用 `source_ref` 关联配图。
- 本任务独立可验收，不依赖其他子任务。

## Background（09-15 勘察）

- 图库已有 09-13 标签体系（`sparkora_image_tag`，UNIQUE(image_id,tag_name)，物理删）与 `GET /api/images?tag=` **单标签**筛选、`GET /api/images/tags`（`data=[{name,count}]`）、单图 `PUT /{id}/tags`（全量覆盖）、`POST /tags/batch`（add/remove）。
- 新闻图 `source=byd-news` 共 157 张，文件名形如 `news-_page_byd-cn_news-2026_detail632.jpg`，其中 `detail632` 对应 `sparkora_news.news_id = /page/byd-cn/news-2026/detail632`，可解析回溯。
- 官方 `tagNames` 无细分价值（167 条全同「公司新闻」）。
- 标题词表命中分布（已验证）：销量 45、出海/车展 59、合作签约 18、技术发布 22、里程碑 25、荣誉 24、财报ESG 6、车展上市 16、社会责任 3；**存在重叠**（如「海外销售再创新高」同时命中销量+出海），语义上确实应多主题。
- `sparkora_image_asset` 无来源关联字段；`created_at` 为同步时间，不能表达新闻发布时间。
- 新闻知识页 `NewsKnowledgePanel.vue` 封面用 `resolveUrl(row.imageUrl)`（官网原始 URL），未接图库。

## Requirements

### R1 主题分类（受控词表 + 标题规则）

- 新增受控主题词表（代码内常量，非 DB 字典表），9 个主题：
  `销量`、`出海`、`合作签约`、`技术发布`、`里程碑`、`荣誉`、`财报ESG`、`车展上市`、`社会责任`。
- 分类器：输入新闻标题，输出命中的主题集合（0~n 个，允许重叠）。规则为关键词正则，需可解释、可复现、零 AI 调用。
- 规则草案（实现时可微调，需在本任务 design.md 固化最终词表）：
  | 主题 | 关键词（正则） |
  |---|---|
  | 销量 | `销售` |
  | 出海 | `海外\|出海\|出口\|全球化\|欧洲\|拉美\|东南亚\|巴西\|泰国\|印尼\|印度\|日本\|澳洲\|澳大\|乌兹\|匈牙利\|墨西哥\|文莱\|哥伦比亚\|香港\|德国\|慕尼黑\|东京\|曼谷` |
  | 合作签约 | `合作\|签约\|携手\|战略` |
  | 技术发布 | `发布\|技术\|刀片\|云辇\|智驾\|平台\|闪充\|芯片\|系统` |
  | 里程碑 | `下线\|里程碑\|万辆\|纪录` |
  | 荣誉 | `荣\|获\|奖\|榜\|500强\|冠军` |
  | 财报ESG | `财报\|业绩\|ESG` |
  | 车展上市 | `上市\|首发\|车展\|亮相` |
  | 社会责任 | `捐赠\|慈善\|公益\|驰援\|救灾\|基金` |
- 无命中主题时：不打主题标签（不强制归「其他」），避免噪音标签。

### R2 时间标签（年份）

- 由来源新闻 `sparkora_news.publish_date` 派生年份标签 `2023`/`2024`/`2025`/`2026`（纯年份字符串）。
- 仅当能解析到来源新闻与发布时间时打年份标签；取不到则跳过。

### R3 标签命名空间

- 主题标签命名 `主题/<主题名>`（如 `主题/销量`），年份标签命名 `年份/2026`。
- 目的：与用户自由标签（如用户自己建的「销量」）隔离，筛选下拉可分组展示；`GET /api/images/tags` 返回的名称即含前缀，前端按 `/` 前缀分组。

### R4 来源追溯（source_ref）

- `sparkora_image_asset` 增列 `source_ref VARCHAR(200)`：新闻图存 `news_id`（如 `/page/byd-cn/news-2026/detail632`）。
- 新增接口 `GET /api/images/{id}/source`：返回 `{sourceRef, news: {id, newsId, title, publishDate, url} | null, imageUrl}`，供图库卡片「来源：<标题>·<日期>」展示与跳原文。
- 存量回溯：解析文件名 `detail<数字>` → 匹配 `news_id` 结尾 `detail<数字>` → 反查新闻 → 打主题+年份标签 + 回填 `source_ref`。零网络成本，幂等可重跑。

### R5 打标时机

- **增量**：新闻入库 `NewsService.upsertOne` 封面转存图库时，同步计算主题+年份标签与 `source_ref` 一并写入（走 09-13 既有 `persistOrReuse` 的 tags 钩子）。
- **存量**：扩展 `ImageTagBackfillRunner`（当前只回溯车型图），增加新闻图回溯分支。
- **人工修正**：复用 09-13 已有单图编辑 / 批量打标（无需新 UI）。

### R6 图库标签筛选升级为多标签 AND

- `GET /api/images` 的 `tag` 参数支持多值（重复参数或逗号分隔），语义为 **AND**（图片须同时具备所有指定标签）。
- 与现有 `source`/`projectId`/`keyword` 筛选可继续组合。
- 前端标签筛选控件改多选，chip 条逐个展示可单独清除。

### R7 新闻知识页封面接图库

- 新闻图入库后，`sparkora_news` 记录其图库 asset id（新增 `cover_image_id BIGINT`，可空）。
- 新闻列表/详情接口返回图库公网 URL（`coverImageUrl`，非持久化派生），前端优先用它，回退原官网 `imageUrl`（兼容未同步/无封面）。
- 新闻卡片展示主题标签，点标签跳图库筛同主题。

## Non-goals

- 不做 AI 图像内容识别，分类完全基于标题文本。
- 不做标签管理页（改名/合并/删除全局标签）。
- 不做图片语义向量检索（属子B）。
- 不追溯新闻正文内嵌图（仍不入库，沿用父任务 Non-goal）。
- 不为新闻分类新增 DB 字典表（词表在代码内，改词表=改代码）。

## Acceptance Criteria

- [ ] 受控 9 主题词表落地为代码常量，分类器输入标题输出命中主题集合，重叠主题可同时命中（如「海外销售再创新高」→ 销量 + 出海）。
- [ ] 新闻同步入库的封面图自动携带 `主题/<命中主题>` 与 `年份/<年>` 标签；无命中主题时只打年份或全无。
- [ ] 存量 157 张 byd-news 图完成回溯：主题+年份标签补齐、`source_ref` 回填；重跑幂等（不产生重复标签行）。
- [ ] `GET /api/images?tag=主题/销量&tag=2026`（或逗号形式）返回同时命中两标签的图；与 `source`/`keyword` 组合生效。
- [ ] `GET /api/images/{id}/source` 返回来源新闻标题/日期/URL；非新闻图（upload/ai-*/byd）返回 `news:null` 不报错。
- [ ] 新闻列表/详情封面 URL 走图库（`coverImageUrl` 非空时优先），官网 `imageUrl` 保留为回退；未同步封面的新闻展示不报错。
- [ ] 新闻卡片的主题标签可点击，点击后跳图库并按该主题筛选。
- [ ] 存量与增量标签命名一致（`主题/`、`年份/` 前缀），人工自由标签不受影响。
- [ ] 权限：读接口三角色、写接口 ADMIN/EDITOR（沿用既有 `@PreAuthorize`）。
- [ ] 零回归：BYD 车型图管线、既有单标签筛选调用、`GET /api/images/tags` 响应结构不变。
- [ ] `mvn -q -DskipTests compile` 与 `frontend/` 下 `npm run build` 通过。
- [ ] `docs/s0-spec.md` §10 与 §7 同步：`source_ref`/`cover_image_id` 字段、主题词表、多标签 AND 语义、来源接口、封面接图库。
