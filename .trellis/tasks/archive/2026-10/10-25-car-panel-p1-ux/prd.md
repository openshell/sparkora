# 车型 Tab P1 交互补齐

> 来源：10-24 知识中心车型页评审 P1 项（P0 三项已由 `10-24-car-ops-async-p0` 收口）。P2/P3 不在本任务范围。

## Goal

补齐知识中心-车型页的五项 P1 交互缺口，让「状态口径、筛选可分享、批量选择、批量栏可及、单车向量维护」形成闭环。

## Requirements

### R1 状态口径统一（筛选/统计/标签同源）
- 现状：卡片标签用 `rowStatusMeta`（含「官网无数据」「数据待复核」「部分同步」），但状态下拉只有 SUCCESS/FAILED/SYNCING/PENDING/EMPTY/NONE，统计条只有 已同步/失败/官网无数据/同步中；「数据待复核」「部分同步」既不可筛选也无计数。
- 要求：抽出单一状态判定（EMPTY > 数据待复核(INCOMPLETE/STALE) > 部分同步(PARTIAL) > syncStatus）；状态下拉补「数据待复核」「部分同步」；统计条补这两项计数；统计项可点击切换对应筛选（点「全部车型」清除状态筛选）。筛选、计数、卡片标签三处口径必须完全一致（含 EMPTY 从「失败」排除、复核优先于失败/部分）。

### R2 筛选状态随 URL 持久化
- 现状：关键词/网络/状态/排序只存在组件内，刷新、分享链接、浏览器前进后退全部丢失。
- 要求：四项筛选写入 `/knowledge` 的 query（`kw`/`net`/`status`/`sort`），挂载时从 query 恢复；清除筛选同时清空 query；浏览器前进/后退恢复对应筛选态；不得污染其他 Tab（Tab 仍非路由）。

### R3 主列表「全选筛选结果」
- 现状：批量操作只能逐卡勾选，筛选出几十台后无法一键全选。
- 要求：EDITOR+ 在结果行提供「全选筛选结果」checkbox（部分选中时 indeterminate）；勾选=选中当前筛选结果全部（已选中的非筛选行保留），取消=清空全部选择；与现有批量栏计数/批量同步/补选中图片/批量删除联动。

### R4 批量栏吸附（sticky）
- 现状：卡片网格较长，滚到下方后批量栏已滚出视野，批量操作需滚回顶部。
- 要求：批量栏在 Tab 内容区滚动时吸附顶部（不被 tab 头部/上下文条遮挡、背景不透明、可正常点击），不改变现有布局与间距。

### R5 单车型「重建向量」入口
- 现状：只有全库「重建全部向量」；单台车型参数/切块异常时无法定向重建，只能跑全库。
- 要求：详情页为 ADMIN 提供「重建向量」操作，创建只针对该车型的 `VECTOR_REBUILD` 异步任务（进度走现有任务面板，终态自动刷新详情）；不传车型时全库重建行为保持不变（回归）。

## Constraints

- 无 DB 迁移；不改指纹/同步/清洗域核心逻辑。
- 后端接口沿用 `R<T>` + 方法级 `@PreAuthorize`；权限：全库与单车型重建均 ADMIN，其余交互沿用既有角色口径（批量操作 EDITOR+，VIEWER 只读）。
- 前端沿用 `useCarSyncJob` 范式（beginStart/终态刷新/卸载清理）；不新增重型依赖。
- PC-only；控件走现有密度/焦点规范（键盘可达）。
- spec 同步：`docs/spec/knowledge/car.md`、`docs/spec/knowledge/center.md`。

## Acceptance Criteria

- [ ] AC1 状态下拉含「数据待复核」「部分同步」；统计条含两项计数；筛选结果、计数、卡片标签三处口径一致（EMPTY 不进失败；复核优先于失败/部分）；点击统计项可切换筛选，「全部车型」清除状态筛选。
- [ ] AC2 任一筛选变更后 URL 带对应 query；刷新/直接打开该 URL 恢复筛选（含排序）；清除筛选后 query 清空；浏览器返回可恢复上一筛选态。
- [ ] AC3 EDITOR+ 可见「全选筛选结果」，勾选选中全部筛选结果、再点清空；部分选中显示 indeterminate；VIEWER 不可见。
- [ ] AC4 内容区滚动时批量栏吸附顶部且可点击，背景不透明。
- [ ] AC5 详情页 ADMIN 可见「重建向量」，创建仅含该车型的 VECTOR_REBUILD 任务并在任务面板显示进度、终态刷新详情；未知 goodsId 返回 400；不传 goodsIds 时全库重建行为不变。
- [ ] AC6 `mvn test` 全绿（含定向重建新用例）；`npm run build` exit 0；Playwright 冒烟（含更新后的 car-panel 用例）全绿。
- [ ] AC7 `docs/spec/knowledge/car.md`（rebuild-jobs body 定向、前端契约）与 `center.md`（车型 Tab 契约）完成更新。
