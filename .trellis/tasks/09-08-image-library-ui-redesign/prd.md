# 图库页 UI/UX 重设计：布局信息层级与交互效率

## Goal

重设计图库独立页 `/images`（`ImageLibrary.vue`），从「信息过密的平铺网格」升级为「以看图找图为核心的高效素材库」。纯前端改动，零后端依赖（全部复用 S10 已有接口）。

## 背景与现状痛点（已核实）

- P1 卡片信息过密：5 层信息（缩略图+2tag+文件名/尺寸+创建人/时间+按钮+模型行）挤在 230px 卡宽
- P2 工具条拥挤：6 控件一行混排，主操作与筛选无视觉层级
- P3 操作按钮常驻：浏览态被「重生成/删除」噪音干扰
- P4 无多选批量：删 N 张点 N 次确认
- P5 预览不连续：大图看完关闭再点下一张
- P6 筛选状态不可见：组合筛选多时迷失，无快清入口
- P7 加载无骨架：切页整页闪白
- P8 空态引导弱：只有文字
- P9 移动端工具条堆叠占首屏

## Requirements（用户已确认：P0+P1 全做 + 悬停层收纳）

- R1 卡片瘦身（悬停层方案）：默认只留缩略图 + 来源小标（icon 圆点）+ 选中态；文件名/尺寸/创建人/模型/操作按钮全部收入 hover 浮层（黑色渐变 overlay 白字）；移动端无 hover → 常显文件名一行 + 「···」更多按钮（action 弹层）
- R2 工具条两段式：左主操作（上传/AI 生图）右浏览控制（搜索加宽为主筛选入口/来源/项目/密度切换/刷新）；移动端浏览控制折叠
- R3 连续大图预览：preview-src-list 传当前页全部原图 + initial-index 定位，左右连续浏览
- R4 筛选状态 chip 条：任一筛选生效时网格上方出现 `来源:文生图 ×` 等可单独关闭的 chip + 「清除全部」
- R5 批量多选删除：hover 出 checkbox / 「批量管理」进入选择模式（工具条切批量态：已选 N|删除|全选本页|取消）；批量删除单次确认，逐张调已有 DELETE 接口，失败聚合提示；被引用图（后端 400）单独列出
- R6 密度切换：舒适(230px)/紧凑(150px) 两档，localStorage 记忆
- R7 懒加载与骨架：el-image 原生 lazy；切页/筛选时网格区骨架占位防闪白
- R8 空态升级：描述 + 「上传图片」「AI 生图」两按钮（复用现有 handler）+ 内联 SVG 占位
- R9 AI 候选「定位到列表」：抽屉候选卡点击后主列表回第一页并高亮该卡 2s（box-shadow 脉冲一次）

## Out of Scope

- 配图抽屉（StepPreview 内）的 UI——本轮只动图库独立页
- 移动端工具条折叠 popover（P2 期，用户未选）
- 卡片出血视觉打磨、生成进度计数（P2 期）
- 图床侧改动
