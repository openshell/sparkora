# prd.md — BYD 王朝发布页渠道接入

> 父任务：`10-16-byd-dynasty-local-push`

## Goal

在 Sparkora 发布步骤中新增比亚迪王朝小程序渠道，让用户清楚看到本地 Agent 状态、预检结果、推送进度和结果。

## Requirements

### R1 渠道切换

发布页支持两个目标：

1. 公众号草稿箱；
2. 比亚迪王朝小程序。

两个渠道独立展示状态，不允许混淆。

### R2 Agent 状态

展示：

- Agent 是否在线；
- Agent 版本；
- 最近预检时间；
- 最近预检结论；
- 具体失败项和中文提示。

### R3 本地预检提示

常见错误必须给明确指引：

- Agent 离线：请在本机启动 Sparkora BYD Agent。
- 微信运行中：请完全退出微信，包括系统托盘。
- MMKV 缺失：请先用微信打开比亚迪王朝小程序。
- MMKV 结构异常：为避免损坏已阻止写入。
- 备份目录异常：请检查本机备份路径。

### R4 车友会信息

- 可使用默认 clubId / clubTitle。
- 也允许发布前在页面确认或修改。
- 校验非空和长度限制。

### R5 推送状态

展示任务状态机：

```text
未创建
排队中
Agent 已接单
本地执行中
推送成功
推送失败
```

成功后显示：

```text
draftId
草稿数量
推送时间
```

失败后显示：

```text
error
任务 ID
重试入口
```

### R6 安全提示

页面上要明确提示：

- 只有微信所在 Windows 机器能完成推送。
- 推送前必须完全退出微信。
- 推送完成后重新打开微信，再到王朝小程序草稿箱查看。

## Acceptance Criteria

- [ ] AC-1 发布页可选择 BYD 渠道。
- [ ] AC-2 Agent 离线时禁用推送按钮。
- [ ] AC-3 预检失败时显示具体阻断项。
- [ ] AC-4 车友会信息可确认或修改。
- [ ] AC-5 点击推送后能看到任务状态实时/近实时更新。
- [ ] AC-6 成功和失败都有清晰提示。
- [ ] AC-7 不影响公众号发布按钮与成功态。
- [ ] AC-8 `npm run build` 通过。

## Notes

- 前端只展示 Server 返回的本地检测结果，不做本机能力假设。
