# prd.md — BYD 本地推送联调与安全验收

> 父任务：`10-16-byd-dynasty-local-push`

## Goal

完成 Sparkora Server、Windows Local Agent 和前端发布页的联调，验证安全边界、失败恢复路径和真机可用性。

## Requirements

### R1 联调场景

必须覆盖：

1. Agent 未启动。
2. Agent 在线但微信仍在运行。
3. Agent 在线但 MMKV 文件缺失。
4. Agent 在线但 MMKV 文件结构异常。
5. BYD 图片上传失败。
6. MMKV 写入中途中断。
7. 草稿数量达到 20。
8. 同一任务重复上报。
9. 多用户权限隔离。
10. 正常推送成功。

### R2 安全验收

- Agent 认证必需。
- 不能用过期或错误 token 领取任务。
- 不能领取不属于授权用户的任务。
- Agent 不得执行 Server 下发的任意命令或脚本。
- 所有 BYD 敏感配置保存在本机 Agent 配置中。
- Server 不保存用户本机路径。

### R3 稳定性验收

- 写入前必须有可用备份。
- 任务失败不能污染公众号发布状态。
- Agent 离线要能从 UI 快速发现。
- 任务超时不能造成双写草稿。
- 重复点击推送不能创建无法追踪的重复任务。

### R4 真机验证

最终需要用户在真实微信 PC 版环境验证：

1. 完全退出微信。
2. Sparkora 创建推送任务。
3. Agent 领取任务并完成本地预检。
4. Agent 上传图片并写入 MMKV。
5. 重开微信。
6. 打开比亚迪王朝小程序草稿箱。
7. 检查标题、正文、换行、图片、车友会标签和草稿数量。

- [ ] AC-2 异常场景全部阻止 MMKV 写入或给出明确恢复指引。
- [ ] AC-3 Agent token 校验与任务归属验证通过。
- [ ] AC-4 BYD 推送状态与公众号发布状态隔离。
- [ ] AC-5 正常真机推送至少成功一次。
- [ ] AC-6 备份文件可用来恢复或比对。
- [ ] AC-7 `mvn test` 与前端构建均通过。
- [ ] AC-8 输出最终部署 / 启动 / 使用说明。
