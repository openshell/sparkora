# 自建高质量汽车资讯信源调研报告

> 撰写：虾仁（claw-expert）｜日期：2026-10-05
> 场景：国内汽车自媒体选题（及时性 + 高质量），部署于 devos 本机自有工具栈
> 实测方法：curl（真实浏览器 UA）直连探测 + Crawl4AI 无头 Chrome 对照实验，全部结论来自当日实测，非经验推断

---

## 一、结论摘要（TL;DR）

1. **三大核心数据站全部可稳定抓取**：车质网零反爬、乘联会有指纹 WAF（无头浏览器可过）、工信部无反爬仅需找准路径。
2. **两个权威站从本机 DNS 不可达**（中汽协、崔东树个人站），改用转载渠道替代，不影响数据获取。
3. **公众号内容是独家富矿且只有一条获取通路**：搜狗微信（本机 SearXNG 已于当日启用该引擎）。
4. 建议按「月度数据定点抓 + 日更要闻靠搜索聚合 + 公众号专题靠搜狗微信」三层组织信源，全部工具已在本机就位。

## 五、与现有工具栈的整合建议

本机已就位的工具链与信源映射：

```
普通 fetch（curl/web_fetch）→ 车质网、工信部列表页、盖世、汽车之家
Crawl4AI（127.0.0.1:11235）→ 乘联会（指纹 WAF）、工信部 SPA 子页、海外深度页
SearXNG（127.0.0.1:5676）  → sogou wechat 公众号 / bilibili 车评 / sogou+360 中文 web
Tavily API                 → 精准长尾（车型+实测+口碑）、time_range 时效过滤
AxonHub 模型聚合           → 多源摘要压缩、选题打分
```

**资源红线**（沿用既有约束）：无头浏览器单实例 300-400MB、swap 偏紧 → Crawl4AI 并发 ≤2，定时任务串行执行；对同一站点每天请求 ≤2 次，避免触发频控升级。

**待落地（需批准）**：每日 08:00 汽车简报自动化（Crawl4AI 抓乘联会+工信部公示+车质网 → Tavily/SearXNG 补隔夜要闻 → 模型压 300 字四栏简报：数据/新车公示/热点/海外，附原文链接）——可行性已由本报告实测验证。

## 六、局限与维护提示

1. 本报告为**单日单机实测**；WAF 策略可能变化，乘联会建议每次抓取后校验返回体（含「行业新闻」字样视为有效）。
2. 中汽协/崔东树站的 DNS 不可达可能是站点方问题（停服/换域名），而非本机网络；每季度复核一次。
3. 盖世汽车页面含 captcha 脚本：默认低风险，若列表页开始返回验证码页，升到 Crawl4AI 抓。
4. 工信部公示列表页的准确路径未在本次定位成功（猜测路径 404），首次接入时需人工从官网导航找一次准确 URL，之后固定使用。
